# MapleDown 1.5

## English

**Build:** 1.5 (1), Universal macOS app for Apple Silicon and Intel Macs.

This is the first release. MapleDown is a light native Markdown app: the page comes first, and the app stays on your Mac.

- Launching with nothing open offers a new Markdown file or an existing one, in a single window. Opening a file leaves that screen; closing the last document brings it back.
- View is for reading. Edit (`⌘E`) is the source.
- The sidebar is the folder you are in. Markdown files in that folder open as tabs. A file from another folder opens in its own window.
- Formulas, tables, and code are rendered locally. Finder Quick Look uses the same page.

**Install:** Download the `.dmg`, open it, and drag MapleDown to Applications. This build is ad-hoc signed and is not Apple notarized. If macOS blocks the first launch, Control-click MapleDown.app and choose **Open**, or allow it in **System Settings → Privacy & Security**. Launch once to register the Quick Look extension.

## 中文

**构建：**1.5（1），同时支持 Apple 芯片和 Intel Mac。

这是第一版。MapleDown 是轻量的原生 Markdown 应用：页面本身就是界面，文件留在本机。

- 没有打开文件时，只出现一个窗口，可以选择新建或打开已有 Markdown。打开文件后离开初始页；关闭最后一个文档会回到初始页。
- 预览用来阅读。编辑（`⌘E`）是原文。
- 侧边栏是当前文件夹。同一文件夹中的 Markdown 以标签打开；其他文件夹的文件开新窗口。
- 公式、表格和代码在本地渲染。访达的 Quick Look 显示同一份页面。

**安装：**下载 `.dmg`，打开后将 MapleDown 拖入“应用程序”。此版本使用 ad-hoc 签名，未经 Apple 公证。若 macOS 首次启动时拦截，请按住 Control 点按 MapleDown.app 并选择**打开**，或在**系统设置 → 隐私与安全性**中允许打开。首次启动后 Quick Look 扩展才会注册。
