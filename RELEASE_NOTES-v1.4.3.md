# MapleDown 1.4.3

## English

**Build:** 1.4.3 (26), Universal macOS app for Apple Silicon and Intel Macs.

**Changes**
- Launching with no file shows the welcome window directly. The system Open panel no longer flashes first.
- Opening a file closes the welcome window. Closing the last document brings it back.
- Clicking a Markdown file in the sidebar opens it or switches to its existing tab. Clicking another file type only selects it; double-click opens it in the default app.
- Switching between already-open Markdown tabs follows the document you clicked.
- Finder and drag opens accept Markdown files and folders. Other files show an unsupported-file alert.

**Install:** Download the `.dmg`, open it, and drag MapleDown to Applications. This release is ad-hoc signed and is not Apple notarized, as with 1.4.2. If macOS blocks the first launch, Control-click MapleDown.app and choose **Open**, or allow it in **System Settings → Privacy & Security**. Launch once to register the Quick Look extension.

## 中文

**构建：**1.4.3（26），同时支持 Apple 芯片和 Intel Mac。

**改进**
- 不打开文件直接启动时，立即显示初始页，不再先闪出系统“打开”面板。
- 打开文件后初始页退出；关闭最后一个文档会回到初始页。
- 点击侧边栏中的 Markdown 文件会打开或切换到已有标签。其他类型的文件单击只选中，双击才用默认应用打开。
- 在已打开的 Markdown 标签之间切换时，会进入所点击的文档。
- 从 Finder 或拖入打开时，接受 Markdown 文件和文件夹；其他文件会提示不支持。

**安装：**下载 `.dmg`，打开后将 MapleDown 拖入“应用程序”。和 1.4.2 一样，此版本使用 ad-hoc 签名，未经 Apple 公证。若 macOS 首次启动时拦截，请按住 Control 点按 MapleDown.app 并选择**打开**，或在**系统设置 → 隐私与安全性**中允许打开。首次启动后 Quick Look 扩展才会注册。
