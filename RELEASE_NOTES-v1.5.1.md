# MapleDown 1.5.1

## English

**Build:** 1.5.1 (2), Universal macOS app for Apple Silicon and Intel Macs.

- Closing the start screen and clicking MapleDown in the Dock opens that screen once.
- Opening a file leaves the start screen. Closing the last document brings it back, still as one window.
- Markdown files in the same folder open as tabs. A file from another folder opens in its own window.

**Install:** Download the `.dmg`, open it, and drag MapleDown to Applications. This build is ad-hoc signed and is not Apple notarized. If macOS blocks the first launch, Control-click MapleDown.app and choose **Open**, or allow it in **System Settings → Privacy & Security**. Launch once to register the Quick Look extension.

## 中文

**构建：**1.5.1（2），同时支持 Apple 芯片和 Intel Mac。

- 关掉初始页后，再从程序坞点开 MapleDown，只会回到这一个初始页。
- 打开文件后初始页退出。关闭最后一个文档会回到初始页，仍然只有一个窗口。
- 同一文件夹里的 Markdown 以标签打开。其他文件夹的文件单独开一个窗口。

**安装：**下载 `.dmg`，打开后将 MapleDown 拖入“应用程序”。此版本使用 ad-hoc 签名，未经 Apple 公证。若 macOS 首次启动时拦截，请按住 Control 点按 MapleDown.app 并选择**打开**，或在**系统设置 → 隐私与安全性**中允许打开。首次启动后 Quick Look 扩展才会注册。
