# MapleDown 1.4.2

## English

**Build:** 1.4.2 (25), Universal macOS app for Apple Silicon and Intel Macs.

**Changes**
- Opening a Markdown file goes straight to that document. Launching MapleDown without a file shows the welcome window.
- Clicking a file in the sidebar opens it or switches to its existing tab, even when its row was already selected.
- The sidebar selection follows the active document tab.
- Switching documents refreshes the browsed folder and external file-change watcher.

**Install:** Download the `.dmg`, open it, and drag MapleDown to Applications. This release is ad-hoc signed and is not Apple notarized, as with 1.4.1. If macOS blocks the first launch, Control-click MapleDown.app and choose **Open**, or allow it in **System Settings → Privacy & Security**. Launch once to register the Quick Look extension.

## 中文

**构建：**1.4.2（25），同时支持 Apple 芯片和 Intel Mac。

**改进**
- 打开 Markdown 文件时直接显示文档；单独启动 MapleDown 时显示欢迎窗口。
- 点击侧边栏文件可打开文档或切换到已有标签，包括再次点击已选中的文件。
- 侧边栏选中状态会跟随当前文档标签。
- 切换文档时更新浏览文件夹和外部文件变更监听。

**安装：**下载 `.dmg`，打开后将 MapleDown 拖入“应用程序”。和 1.4.1 一样，此版本使用 ad-hoc 签名，未经 Apple 公证。若 macOS 首次启动时拦截，请按住 Control 点按 MapleDown.app 并选择**打开**，或在**系统设置 → 隐私与安全性**中允许打开。首次启动后 Quick Look 扩展才会注册。
